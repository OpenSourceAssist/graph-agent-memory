= Python SDK
:description: Select a Python SDK artifact or checkout, then choose Bolt or NAMS setup.

The Python SDK connects directly to Neo4j over Bolt or to NAMS over HTTP. Supported methods, result shapes and data scope differ; see xref:reference/backend-capabilities.adoc[backend capabilities].

== Select a release or a checkout

The public PyPI package and this source checkout can have different APIs even when their version strings match. On 13 September 2026, PyPI's latest wheel was `0.5.0`; its exports did not include the current `connect`, `BoltSettings` or `NamsSettings` factory entry points. These docs' factory examples therefore require the checkout until a matching artifact is verified.

To install a selected release:

[source,bash]
----
python -m pip install 'neo4j-agent-memory==0.5.0'
----

Use that release's documentation and inspect its available extras/API. To run the maintained source lessons, clone this repository and follow the lesson's `uv sync` commands. Install the named provider/framework extra; `[all]` does not include every local model dependency.

== Looking for the TypeScript SDK?

See xref:sdks/typescript.adoc[TypeScript SDK]. Python and TypeScript applications can share supported NAMS data in the same authorized workspace. This does not imply identical local APIs or automatic cross-process conversation recall.

== Runnable examples

The https://github.com/neo4j-labs/agent-memory/tree/main/examples[examples directory] contains small scripts, framework integrations and full applications. Use each README's dependency, backend and source-versus-release requirements. Application test fakes do not establish hosted service support for every demonstrated business operation.
