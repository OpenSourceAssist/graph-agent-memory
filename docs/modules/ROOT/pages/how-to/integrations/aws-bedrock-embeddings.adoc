Generate Titan V2 vectors, check their size, and persist a message through a MemoryClient using the same embedder. The selected path uses AWS credentials from the normal SDK credential chain and an explicitly configured region.

== 1. Prepare the selected environment

Install the AWS CLI before running the identity check below.

anchor:_prerequisites[]
anchor:_authentication[]

Use Python 3.10+ and the current repository checkout. Start a dedicated Neo4j 5.26+ database; its existing vectors and indexes must match the selected model and dimensions. The program disables entity extraction and does not require a chat model.
[source,bash]
----
python -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[bedrock]"
export AWS_REGION='us-east-1'
export NEO4J_URI='bolt://localhost:7687'
export NEO4J_PASSWORD='replace-with-your-database-password'
aws sts get-caller-identity
----

Configure an AWS profile, role or environment credentials before the final command. The identity must be allowed to invoke `amazon.titan-embed-text-v2:0` in the selected region; successful STS identity lookup alone does not establish model access. The chosen model emits 1024-dimensional vectors in this adapter configuration.

== Troubleshooting and cleanup

anchor:_troubleshooting[]
anchor:_slow_performance[]

Stop when the program raises an exception; a printed model response alone does not verify persistence. Check the configured database, provider access and vector dimensions before retrying. The program prints the session or trace IDs needed for inspection and closes the client. Retained example records remain in the dedicated database; remove that disposable database only when you no longer need them. Reusing a session groups records; it does not authorize a user to read them.

== Adapt the integration

anchor:_supported_models[]
anchor:_basic_configuration[]
anchor:_using_with_environment_variables[]
anchor:_configuration_options[]
anchor:_see_also[]

`BedrockEmbedder` accepts `model`, `region_name`, optional `profile_name`, `batch_size` and `normalize`. The current adapter's `embed_batch()` coordinates individual `embed()` calls in bounded groups; it is not a promise that Titan accepts a 25-document payload. Embedding execution is a remote API operation, not a CPU-bound Lambda workload by definition.

The adapter contains mappings for Titan V1/V2 and Cohere embedding models. Mapping a model ID is not proof that it is available in every AWS region or account. Check access for the selected model instead of relying on a static region list. Provider error codes distinguish authentication, access, throttling and invalid configuration; changing regions blindly can make the mismatch worse.

See xref:how-to/integrations/aws-strands.adoc[Use with Strands] for agent integration and xref:how-to/configure-embedding-provider.adoc[Configure embeddings] before changing an existing vector model. The recipe's shared setup accepts the explicit embedder object, so OpenAI credentials are not required here.

See xref:reference/backend-capabilities.adoc[Backend capabilities and scoping] before adding hosted or multi-user behavior. Neo4j Agent Memory is a Neo4j Labs project with community support.
